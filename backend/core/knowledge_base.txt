MODULE 1: FEATURE ENGINEERING (DATA EXCHANGE)

Overview and Workflow:
The AI Feature Engineering module is a 6-step wizard designed to ingest raw data, analyze it, clean it via AI, generate new predictive features, apply custom transformations, and export the ready-for-ML dataset. It is located under Data Exchange > Feature Engineering.

Step 1: Select Dataset (Upload)
Purpose: Where users bring their data into the platform. Users can upload a CSV or Excel file via drag-and-drop or file browser. The system parses the file and outputs a summary showing filename, file size, row/column count, and a Data Preview table. Users can also import datasets from Azure Blob Storage (team outputs from Anonymization or other pipelines). Click Continue to Data Profiling.

Step 2: Data Profiling (The Dashboard)
Purpose: A read-only analytical dashboard to understand data distribution and health before applying machine learning. It has 5 tabs:
Tab 1 Overview: High-level dataset statistics. Shows Total Rows, Columns, Missing Data Percentage, Column Type Distribution pie chart, Data Health Score progress bar, and Dataset Memory Footprint.
Tab 2 Data Quality: Shows Completeness Score (percentage of non-missing data) and Feature Richness.
Tab 3 Distributions and Metrics: 
- Explore Individual Features: Histograms, Quick Stats, and a Skewness Gauge. Green means Symmetric, Red means Highly Skewed. If red, the user should apply a Log or Square Root transformation in Step 4.
- All-Features Overview: Outlier Detection box plots. Feature Scale Comparison bar chart (if scales differ vastly, user must scale data in Step 4). Data Spread (Red means wildly chaotic). Data Completeness (Red means severe missing data). Category Dominance (Red means column is almost entirely one value and should be dropped). Cardinality Overview (Red means too many categories, requires Target Encoding). Correlation Matrix (Highly correlated features can be dropped).
Tab 4 Missing Values: A table and stacked bar chart showing exact missing rows per column.
Tab 5 Column Details: Raw data dictionaries for Numeric and Categorical features.

Step 3: Data Quality (AI Cleaning)
Purpose: Fixing issues identified in Step 2. The system uses an LLM to suggest Python code for imputing null values, handling duplicates, and capping outliers. Users can view the Python code, ask the LLM to edit it in the interactive editor, and click Apply to execute the code.

Step 4: Feature Generation (AI Feature Engineering)
Purpose: Creating new columns to make ML models smarter. AI suggests novel features. Users can accept/reject suggestions, manually prompt the AI, apply math transformations (Log, Sqrt) to fix skewness, or apply Scaling to fix scale mismatch.

Step 5: Custom Transformation using AI
Purpose: Transform data as per user needs. Users manually type prompts to ask the AI to delete, add, or apply custom changes to any columns. Users can preview live data and apply changes in real time.

Step 6: Export Step
Purpose: Final review. Displays a preview of the final dataset and a summary of applied transformations. Click Download CSV. Exported datasets are also saved to Azure Blob Storage for use in other modules like AutoML.

Common Questions for Feature Engineering:
If a user asks how to handle missing data, guide them to Step 2 Missing Values tab, then Step 3 Data Quality.
If a user asks about Skewness, explain it means lopsided data and tell them to use a Log Transform in Step 4.
If a user asks about Category Dominance, explain that if it is over 90 percent, the column is useless for ML and should be dropped.
If a user asks to write their own code, tell them Step 3 and Step 4 have interactive code editors.
If a user asks about preparing data for ML training, guide them through the full 6-step pipeline and mention they can export the result and use it directly in the AutoML Wizard.

MODULE 2: OCR AND DOCUMENT INTELLIGENCE (DATA EXCHANGE)

Overview: 
The OCR and Document Intelligence module is a powerful tool for converting scanned documents, PDFs, and images into editable, searchable text. It uses Azure Document Intelligence (Form Recognizer) for high-accuracy text extraction and table detection. It is located under Data Exchange > OCR Conversion.

Capabilities:
- Extract text from scanned PDFs, images (JPG, PNG, TIFF), and multi-page documents.
- Detect and extract structured tables from documents and export them as markdown or CSV.
- Generate AI-powered insights including document summaries, language detection, and named entity recognition (NER) for people, organizations, locations, and dates.
- Semantic search across all processed documents to find specific information quickly.

Interaction Steps:
Step 1: Upload the Document. Users can upload PDFs or images. Specify whether to extract text, tables, or both. The system returns a unique Job ID and processes in the background for large documents.
Step 2: Poll Processing Status. Using the Job ID, the system checks the status (pending, processing, completed) and shows a progress percentage. Users can continue working while the document processes.
Step 3: Retrieve Results. Once completed, it fetches full extracted text, markdown tables, and AI insights (document summary, language, and named entity recognition). Results are displayed in a clean, interactive dashboard.
Step 4: Semantic Search. Processed documents are indexed so users can search for text snippets to get data-backed answers. This is useful for large document collections where manual searching is impractical.

Common Questions for OCR:
If a user asks about extracting text from a PDF, guide them to the OCR tool under Data Exchange.
If a user asks about table extraction, explain that the tool can detect tables in documents and export them.
If a user asks about searching through documents, explain the semantic search feature in Step 4.
If a user has handwritten documents, explain that the Azure Document Intelligence service supports handwriting recognition.

MODULE 3: DATA ANONYMIZATION (DATA EXCHANGE)

Overview:
The Data Anonymization module protects user privacy by automatically detecting and redacting Personally Identifiable Information (PII) from structured datasets (CSV/Excel) and unstructured data (text, images, and documents). It uses a multi-layered approach combining Regex pattern matching, Microsoft Presidio (NLP-based entity detection), and Azure OpenAI LLM for context-aware anonymization. It is located under Data Exchange > Data Anonymization.

Capabilities:
- Detect PII entities: Names, email addresses, phone numbers, SSNs, credit card numbers, addresses, dates of birth, passport numbers, and more.
- Multiple anonymization strategies: Masking with asterisks, replacing with synthetic/fake data, hashing, or complete removal.
- Support for structured data (CSV/Excel columns) with per-column PII detection and visual risk scoring.
- Support for unstructured text documents with inline PII highlighting and redaction.
- Privacy risk dashboard showing detected PII categories, risk severity levels, and compliance metrics.
- Export anonymized data in the original format for downstream use.

Interaction Steps:
Step 1: Navigate to the Data Anonymization tool under Data Exchange and upload a dataset (CSV/Excel) or a document (text/PDF).
Step 2: The system automatically scans and analyzes the file. For structured data, it presents a visual privacy risk summary showing which columns contain PII (names, emails, phone numbers, etc.) with risk severity indicators. For text documents, it highlights detected PII inline.
Step 3: Choose a preferred anonymization strategy: masking with asterisks (e.g., J*** D**), replacing with synthetic data (e.g., John Doe becomes Alex Smith), hashing for consistent pseudonymization, or complete removal.
Step 4: Click Anonymize Data. The system processes the file and presents a before/after comparison. Download the secured, privacy-compliant file. Anonymized datasets are also saved to Azure Blob Storage for use in other modules.

Common Questions for Data Anonymization:
If a user asks about GDPR compliance, explain that the tool detects and redacts PII to help meet privacy regulations.
If a user asks about the difference between masking and synthetic data, explain that masking replaces characters with asterisks while synthetic data generates realistic fake replacements.
If a user wants to anonymize a dataset before sharing it, guide them to upload the file and choose an anonymization strategy.
If a user asks about which PII types are detected, list: names, emails, phone numbers, SSNs, credit cards, addresses, dates of birth, and more.

MODULE 4: DATA VISUALIZATION (DATA EXCHANGE)

Overview:
The Data Visualization module provides an advanced, interactive suite for exploring structured datasets (CSV and Excel files) with rich statistical profiling, AI-powered chart recommendations, and multiple visualization types. It is located under Data Exchange > Data Visualization. Users can also browse and analyze datasets from the Indian Government Open Data Catalog (data.gov.in) directly.

Capabilities:
- Upload CSV or Excel files for instant statistical profiling and visualization.
- Data Preview: View the first 100 rows of any dataset in a scrollable, interactive table.
- Column Statistics: For every column, see data type, null count, unique values, min, max, mean, standard deviation, and top category (for categorical columns).
- Interactive Charts: Generate 6 types of visualizations:
  1. Bar Chart: Compare values across categories. Great for seeing sums or averages by group.
  2. Line Chart: Track trends over time or sequential data. Ideal for time-series analysis.
  3. Scatter Plot: Explore relationships between two numeric variables. Useful for correlation analysis.
  4. Pie Chart: Show proportional distribution of categorical data.
  5. Area Chart: Similar to line charts but with filled areas to emphasize volume changes.
  6. Histogram: Understand the frequency distribution of numeric data. Great for detecting skewness and outliers.
- AI Recommendations: The system uses Azure OpenAI to analyze column statistics and suggest the most insightful charts to create. It recommends which columns to plot on X and Y axes and explains what insight each chart would reveal.
- Chart Export: Download any generated chart as a PNG image for reports and presentations.
- Government Data Catalog: Browse, search, and filter thousands of datasets from data.gov.in. Select a dataset and the system fetches the full data (up to 100k rows) for analysis without manual download.

Interaction Steps:
Step 1: Navigate to Data Visualization under Data Exchange. Choose between the Data Catalog tab (to browse government datasets) or the AI Analysis (Upload) tab.
Step 2: If uploading, select CSV Data as the analysis type, then upload a CSV or Excel file. Alternatively, use the Quick Demo sample dataset.
Step 3: The system processes the file, displaying Total Rows, Total Columns, and the Filename. Switch between Data Preview and Statistics tabs to explore the dataset.
Step 4: In the Visualizations tab, select X-axis and Y-axis columns, choose a chart type (Bar, Line, Scatter, Pie, Area, or Histogram), and apply aggregation (Sum, Average, Count, Min, Max) if needed. Click Generate Chart.
Step 5: Use the AI Recommendations panel to get smart suggestions for the most meaningful visualizations based on your data.

Common Questions for Data Visualization:
If a user asks how to visualize their data, guide them to the Data Visualization tool and suggest starting with a Bar Chart or Histogram.
If a user asks about understanding data distributions, recommend using Histograms to see frequency patterns and detect skewness.
If a user asks about finding correlations, suggest using Scatter Plots to explore relationships between numeric columns.

MODULE 5: AUTOML WIZARD (MODEL EXCHANGE)

Overview:
The AutoML Wizard is a no-code machine learning tool that lets users train, evaluate, and compare ML models automatically. It supports Classification, Regression, and Clustering workflows. It uses H2O AutoML for classification and regression (training multiple models and producing a leaderboard), and scikit-learn for clustering (K-Means, DBSCAN, Agglomerative, Gaussian Mixture). It is located under Model Exchange.

Capabilities:
- Upload datasets or import from Azure Blob Storage (including outputs from Feature Engineering or Anonymization).
- Automatic problem type detection: Classification (for categorical targets), Regression (for numeric targets), and Clustering (unsupervised grouping).
- H2O AutoML Leaderboard: Trains multiple algorithms (GBM, XGBoost, Deep Learning, GLM, Random Forest, Stacked Ensembles) and ranks them by performance.
- Clustering Analysis: K-Means with elbow method, DBSCAN, Agglomerative, and Gaussian Mixture. Includes Silhouette Score evaluation and interactive cluster visualizations (PCA scatter plots, radar charts, parallel coordinates).
- Model Performance Metrics: Accuracy, AUC, Logloss, RMSE, MAE, R-squared, Confusion Matrix, and more.
- Feature Importance: See which columns contribute most to predictions.
- Real-time training logs streamed via WebSocket for live progress monitoring.
- Dynamic statistics dashboard tracking total experiments, models trained, and average training time.

Workflow Steps:
Step 1: Select Dataset. Upload a CSV file or import from Azure Blob Storage team outputs. The system shows a data preview and basic statistics.
Step 2: Configure. For Classification/Regression: select the target column, set training time (max runtime in seconds), choose the number of folds for cross-validation. For Clustering: select feature columns, choose algorithm (K-Means, DBSCAN, etc.), set number of clusters (or auto-detect with elbow method).
Step 3: Training. Click Start Training. For Classification/Regression, H2O AutoML runs multiple algorithms in parallel and streams live training logs via WebSocket. For Clustering, the algorithm runs and evaluates cluster quality using Silhouette Score.
Step 4: Results. View the model leaderboard ranked by performance metrics. Explore Feature Importance charts, Confusion Matrix (for classification), and detailed model comparisons. For Clustering, view PCA scatter plots with cluster assignments, radar charts for cluster profiles, and parallel coordinate plots.

Common Questions for AutoML:
If a user asks about training a model, guide them to the AutoML Wizard under Model Exchange.
If a user asks what Classification is, explain it predicts categories (e.g., spam vs not spam, churn vs no churn).
If a user asks what Regression is, explain it predicts numeric values (e.g., house prices, sales revenue).
If a user asks what Clustering is, explain it groups similar data points without a target variable. Useful for customer segmentation, anomaly detection, etc.
If a user asks about the best model, explain H2O AutoML trains multiple algorithms and the leaderboard shows which performed best.
If a user asks about preparing data for AutoML, recommend using the Feature Engineering module first to clean and enhance the dataset, then export and import into AutoML.
If a user asks about feature importance, explain it shows which columns have the most impact on predictions.
